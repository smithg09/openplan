PR #482: Move sessions to Redis

Sessions move from the primary database to Redis with a 30 minute sliding expiry. Login latency drops, and the sessions table stops being the largest write source.

What changed

- INSERT INTO sessions (id, user_id, expires_at) VALUES ($1, $2, $3)
+ SET session:{id} {user_id} EX 1800

- UPDATE sessions SET expires_at = now() + interval '30 min' WHERE id = $1
+ EXPIRE session:{id} 1800

Why now

Session reads are 41% of primary read traffic and each request writes the row to extend it. Redis handles both without touching the database.
